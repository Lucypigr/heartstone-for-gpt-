## 資料來源與更新方式

卡名、繁體中文敘述、費用、體質與衍生卡來自 [HearthSim 的 CardDefs.xml](https://raw.githubusercontent.com/HearthSim/hsdata/master/CardDefs.xml)，本批使用 build `255130`。《泰坦》系列 ID 是 `1858`，包含迷你系列的 `YOG_` 卡。其他系列維持原本的 build `253932` 資料；局部更新版本記在 `cards.json` 的 `setBuilds`。

```bash
npm ci
npm run cards -- --set=1858
npm test
npm run build
npm run dev
```

產生器會沿用 `.cache/CardDefs.xml`；沒有快取時才會下載。`--set=1858` 只合併本系列及所需衍生卡，保留其他系列與已收錄的卡，不會因本次解析失敗而刪掉舊卡。重複執行的輸出已檢查一致。

目前不建議用新版本來源直接全量重建舊資料：已觀察到舊覆寫 `CAP_405` 引用的 `CAP_405t1` 無法在本次來源建立。這個既有的跨版本問題需在更新該系列時另外處理。

## 本批實作

### 泰坦

加入 11 個職業的泰坦與「解放的尤格薩倫」，共 12 位，每位三個一次性能力。

- 泰坦上場即可使用能力，不需要等召喚疲勞結束，也不要求有攻擊力。
- 能力消耗本回合的一次攻擊機會；風怒／超級風怒提供額外次數。
- 冰凍、休眠或已耗盡本回合次數時不能使用能力；對手回合也不能操作。
- 三個能力全部使用後，才恢復一般攻擊，仍受當回合攻擊次數限制。
- 能力不是出牌、戰吼、法術或英雄能力。法術傷害不會增加泰坦能力的傷害，飄渺不阻止泰坦能力指定。
- 沉默移除泰坦限制與其被動能力；複製保留已使用技能，重生建立新的技能紀錄。
- 一般隨機產生卡牌排除泰坦；阿曼蘇爾的明確傳說發現效果允許泰坦。

個別泰坦的加倍能力、武器升級、強制攻擊、移除而非死亡、符文發現、左右位置光環、傷害上限與永久傳送門都有獨立效果處理。

薩格拉斯的門占一個戰場位置，但不算手下、不觸發召喚手下效果、不接受手下光環。門與建立它的薩格拉斯透過實體 ID 連結；沒有戰吼建立門的薩格拉斯不能借用另一個門。傳送門持續在回合結束召喚惡魔，薩格拉斯離場後仍存在。

### 鑄造（鍛造）與伊格尼司

加入全部 18 張具有鑄造的可收藏卡及其升級版本。

- 在自己的回合花費固定 2 點法力，直接升級手中的卡。
- 不需要先付得起該卡的出牌費用，也不需要戰場有空位。
- 保留手牌的費用與體質加成，不觸發出牌、戰吼、連擊或施法事件。
- 法力支出會計入持有手牌期間的支出；花光最後法力時仍觸發相應事件。
- 風暴巨人可反覆鑄造減費；熔鑄匠複製的是升級後且帶有手牌加成的卡。
- 伊格尼司依序選擇 1／5／10 費武器、第一個效果與第二個效果。合成資料保存在個別手牌與武器上，涵蓋關鍵字、戰吼、攻擊後效果與亡語。
- 「攻擊時免疫」涵蓋攻擊期間觸發的陷阱與戰鬥傷害，並在攻擊結束後解除。

### 磁力與觸鬚

加入 13 張磁力或磁力支援卡、火花機器人與觸鬚相關卡。

- 吸收寄生怪可以吸附機械或野獸；一般磁力仍只吸附機械。
- 滿場時可吸附到合法目標，不能在不合法位置放出第八個手下。
- 吸附後保留冰凍傷害、順劈、攻擊觸發與亡語等效果。
- X-21 記錄吸附的卡牌並在亡語回收；機械跳蛙傳遞加成與亡語。
- SP-3Y3-D3R 的暫時潛行會在下個己方回合消失。
- 混沌觸鬚從 1 費法術開始升級，最高 10 費，並顯示目前費用。

## 玩家操作與 AI

點選手牌可使用畫面下方的鍛造按鈕；高費卡即使不能打出也能鍛造。點選場上泰坦會顯示三個能力及使用狀態；需要目標時，再點有效角色。放置磁力手下時可點選要吸附的友方手下。AI 會列出合法的鍛造與泰坦能力動作，並在模擬中評估結果。

桌機與 390 × 844 手機視窗均已實際操作驗證高費手牌鍛造、泰坦選項、目標選擇及傷害結算，未出現 JavaScript 頁面錯誤。

## 其餘卡片與共用規則

- 記錄已施放的不同法術學派，供希芙、諾甘農的智慧、探索魔法與元素鼓舞使用；希芙的卡面顯示即時數值。
- 星界自動機使用召喚歷史光環；土靈在各自召喚時依歷史獲得加成。幼苗在自己的回合開始計時綻放。
- 霍迪爾記錄接下來三個打出的手下；歐丁在所有護甲來源上轉換當回合攻擊力；黑爾雅讓對手的瘟疫抽到後重新洗入；卓頓每回合複製第一張抽到的法術。
- 支援抽到時召喚的巨人、符文裝飾賦予的抽到時施放、嚴寒凍結鎖牌、導電的相鄰目標、跨回合保存的下一次法術傷害與治療轉傷害。
- 加入柯洛剛恩的抓取與歸還、萊公、洛肯、提爾、彌米倫的六種工具、艾爾加隆的牌堆頂選擇與其他條件戰吼、亡語、武器效果。
- 丘加利在開局以 50% 機率選擇 20 種異常之一，雙方共用；包含開局卡牌、英雄能力、費用、牌堆與回合末效果。異常名稱會顯示在對戰上方。需要的舊尤格薩倫與變幻者澤魯斯也收錄為衍生依賴。

異常來源為本次 CardDefs 的 `TTN_002t*`。另以 2023 年 build `185749` 交叉查核異常名稱及敘述，行為採 build `255130`，例如「扭曲現實」只複製每回合第一張牌；丘加利採目前 50% 而非初版 25%。

## 驗證範圍與限制

目前全套 **26 個測試檔、894 項測試通過**；`npm run build` 通過。

- 卡名、費用、攻擊、生命／耐久、關鍵字及衍生卡來自所記錄的 CardDefs 版本；地點的耐久由其地點欄位表示。
- `titans.test.ts` 驗證泰坦、鑄造、伊格尼司與磁力；`titans-rest.test.ts` 執行其餘卡片及各個二選一選項，並驗證跨回合規則、20 種異常的出現與代表性效果。
- 全套測試另外涵蓋所有可收藏卡出牌與 AI 完整對局。桌機和 390 × 844 手機視窗實際驗證鍛造、泰坦選項、選目標及傷害，沒有頁面 JavaScript 錯誤。
- 正式建置仍有原本的大型 bundle 提醒。局部卡庫重建已檢查輸出一致；既有其他系列卡片不隨本次更新改版。
- 尚未與官方客戶端逐一對照全部跨系列、複製／變形、觸發順序與極端滿手／滿場組合；因此不能保證 100% 與原版相同。金色異常使用本站的金色外框樣式，沒有官方金卡動畫。
