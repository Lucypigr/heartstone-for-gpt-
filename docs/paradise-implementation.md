# 天堂島補卡與機制

《天堂島》（系列 `1905`，含旅行社迷你系列）從 **34 張增加到 183／183 張**，新增 **149 張**。全遊戲可收藏卡共 **4,385 張**。新增清單見 [paradise-added.csv](paradise-added.csv)。

先補共用規則，再逐張加入效果；沒有以只有卡面、沒有作用的可收藏卡充數。以下驗證不代表已和官方客戶端逐一比對所有跨系列互動。

## 資料與參考

- 卡名、繁中卡文、費用、體質、關鍵字與衍生卡：HearthSim [CardDefs.xml](https://raw.githubusercontent.com/HearthSim/hsdata/master/CardDefs.xml)，build `255130`。這是該版本的規則，部分數值與 2024 年發售時不同。
- 另查核 [2024 年的 CardDefs](https://raw.githubusercontent.com/HearthSim/hsdata/fa1e19923f57546cdb623a6aa30e34cea8b57b21/CardDefs.xml)，確認原始衍生卡結構。
- 藥劑混合師的九種一費材料、賽佛瑞斯的三種固定旅行團候選：Firestone [`@firestone-hs/reference-data` 3.0.218](https://www.npmjs.com/package/@firestone-hs/reference-data) 的 `RELATED_CARDS_DATA`（MIT）。旅行團使用固定清單，並對應本站已收錄的同名卡版本；沒有以費用或效果篩選的任意卡池取代。

## 遊客：組牌與戰鬥分開處理

包含本體十一位與迷你系列兩位，共十三位遊客。

1. 只有本職業的遊客能開放它指定的目的職業。
2. 可帶入目的職業的天堂島卡，包含迷你系列；其他擴充卡與目的職業的遊客不在開放範圍。
3. 不可利用外職遊客繼續開放第三職業。本職業的兩位不同遊客可各自開放目的職業。
4. 旅遊資格在組牌時決定，不需要在戰鬥中抽到或打出遊客。
5. 收藏篩選、套牌驗證、牌組代碼匯入與自動補牌都會檢查同一個規則。移除遊客後，留下的外職卡會顯示為不合法；死亡騎士符文限制仍適用。

遊客本身另有各自戰吼、亡語或被動效果，並非只有組牌標籤。包含艾蘭娜的己方回合英雄傷害轉移、暗髓的雙重亡語與摧毀、萊妮莎按實際費用施放兩次，以及維斯塔的三回合後重放。

## 飲料與選擇機制

六種飲料都有三個杯數版本。每杯是獨立法術，要重新支付費用；施放成功後補下一杯，最後一杯不再補牌。單張卡的降費不會直接傳給新的一杯。被反制時不補杯；施放兩次則分別產生下一杯。

神聖啤酒可給英雄聖盾；海息酒杯依此版官方 `ImmuneToSpellpower` 標籤，不獲得法術傷害加成。肌肉杯杯會讓玩家選擇要強化的手牌。

「選三次」先連續做三次選擇，可重複選同一項，再依序結算。藥劑混合師從九種一費材料選兩種，成品保存兩種效果、目標需求與組合卡文。

## 地點、手牌與跨回合狀態

- 地點與手下共用七個戰場位置；啟用記錄可降低海濱巨人費用，並觸發 XB-931 管家。
- 天堂島原有的重新開放條件繼續作用；加入地點召喚、複製及沙灘魔堡的手下／地點互換。
- 傳單在己方回合開始時翻面，保留費用變化；乳酪升級、熊的手牌成長、撥號機器人的數字也有各自狀態。
- 潮池幼生記錄持有期間的法術；克蕾絲按兩種不同學派選出官方對應變形；命運牌會隨牌堆頂更新。
- 麵包會把中間的手下裝入三明治；行李箱保存牌堆頂的卡牌；適應型聚合體保存附魔後洗回牌堆。
- 新高度提高法力上限；什錦果仁只在指定回合暫時增加水晶，受上限限制。「暫時」包含起手手牌與後來抽到的版本。
- 支援噴發升級與抽到施放、連續元素回合、自己的回合受傷次數、法術指定角色次數，以及永久冰凍與傷害上限。

## 驗證與網站操作

全套 **27 個測試檔、1,109 項測試通過**；新增的天堂島測試共 **215 項**。正式建置與型別檢查通過。其他系列既有卡牌資料變更為零、沒有刪除舊卡，局部重建的輸出雜湊一致。

新增 `src/engine/paradise.test.ts`，包含全部 183 張可收藏卡的實際出牌與回合結算，以及遊客、飲料、選三次、翻面、地點、延遲施法、自訂藥水、固定旅行團、命運牌、三明治等互動測試。

全套測試包含既有全卡出牌、AI 完整對局、卡面文字與機制說明檢查。新增天堂島卡包，卡池包含本系列 183 張卡。首頁底部顯示天堂島數量與部署版本；收藏也分開顯示系列總數和目前篩選結果。

操作驗證涵蓋桌機及 390 × 844 手機視窗：選取天堂島看到 183 張；將遊客加入法師牌組後，聖騎士分頁與合法外職卡可使用；戰鬥中完成三次選擇並得到正確體質。

仍未與官方客戶端窮舉所有複製、變形、滿手／滿場和跨系列觸發順序；不能將測試通過描述為與原版百分之百相同。

## 重建

```bash
npm ci
npm run cards -- --set=1905
npm test
npm run build
```

產生器沿用 `.cache/CardDefs.xml`。局部更新保留其他系列既有資料與泰坦的來源版本。網站由 `main` 的 GitHub Actions 自動部署；可用 `play.html` 入口與頁尾版本確認更新。
